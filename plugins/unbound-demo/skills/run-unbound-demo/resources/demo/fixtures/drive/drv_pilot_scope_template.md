# Three-Day Install Scope & Success Criteria

**Drive ref:** drv_pilot_scope_template · **Stage:** technical-validation · **Vertical:** Any

The scope sheet for a three-day install, with the pass and fail criteria agreed before day one.
For buyers who have sat through a six-month rollout before and assume this is another one.

- Names the sources read, the deals in scope, and the desks the agent is installed for.
- Sets pass and fail up front, plus the date the engagement closes, so the scope cannot drift.
- Bounded on purpose: three days, one fee, and the config stays with you at the end of it.
