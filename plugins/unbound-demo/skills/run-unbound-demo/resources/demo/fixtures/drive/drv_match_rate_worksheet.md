# Approval-Rate & Minutes-Reclaimed Worksheet

**Drive ref:** drv_match_rate_worksheet · **Stage:** technical-validation · **Vertical:** Any

The worksheet for measuring what the install gives back on your own desk — the baseline week
against the first live week. For deals where someone says the admin time is not really costing
them much, and wants that proved rather than asserted.

- Names exactly what gets counted: admin minutes per rep, approval rate, edits before approval.
- Fixes the baseline week and who logs it, so the comparison is like for like and holds up later.
- Ends in one defensible number for the minutes reclaimed, agreed before the goalposts can move.
